# Diff-VTuberv2: Extension Assistant

Instructions and design records for developing Worlds, providers and bots, or migrating an existing implementation.

## Usage

1. Open this directory with a coding assistant and describe the desired feature.
2. Use the framework source, documentation and templates in the sibling `Diff-VTuberv2/` directory.
3. Develop packages under `state/packages/` and record designs under `state/design/`.
4. Run each package's type checks and tests, then validate its contracts from the framework directory.

## Files

- [AGENTS.md](AGENTS.md): operating conventions.
- [app/](app/README.md): reading guides, workflows and environment notes.
- `state/JOURNAL.md`: progress notes.
- `state/design/`: design records.
- `state/packages/`: extension packages.

This workspace does not automatically initialize repositories or connect to the original project's remotes.
